# revisao_conceitos
questao 10:
A. Histórico do navegador:
Pilha - espera-se retornar à página visitada mais recentemente, não à mais antiga. Isso é comportamento LIFO (último a entrar, primeiro a sair)
B. Pessoas aguardando atendimento:
Fila - o critério é ordem de chegada. quem chegou primeiro deve ser atendido primeiro. Isso é comportamento FIFO (primeiro a entrar, primeiro a sair)
C. Catálogo de produtos:
Lista - o usuário precisa poder acessar ou buscar produtos em qualquer posição, independentemente de quando foram cadastrados. Uma lista é a melhor opção
D. Função “desfazer” de um editor de texto:
Pilha - espera-se retornar à ação mais recente, não à mais antiga. Isso é comportamento LIFO (último a entrar, primeiro a sair)
E. Playlist de músicas que pode ser acessada por posição:
Lista - o usuário precisa poder acessar a musica que ele quer independentemente da posição. Uma lista é a melhor opção
